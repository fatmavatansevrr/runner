# Appsel Backend Phase Ledger

This ledger records repository-backed phases only. A phase may be used as a parent authority only when it has a real report and verified repository provenance. `MASTER_ROADMAP.md` planned entries are not parent authorities.

**Phase types**: `EVIDENCE` · `DECISION` · `ARCHITECTURE_DESIGN` · `DESIGN_VERIFICATION` · `IMPLEMENTATION` · `VERIFICATION_CLOSURE` · `CHECKPOINT` · `GOVERNANCE`

**Execution Status is separate from Final Classification.** A phase can have Execution Status `DONE` while its Final Classification records a blocker (e.g. `FREQ6D3_BLOCKED_ON_ARCHITECTURE_DECISION`) — the assessment/design/implementation work itself completed; what it *found* may still be a blocker.

**Provenance**: `VERIFIED` (report file exists in this repo at the listed path, and the listed commit SHA is reachable from the HEAD this ledger was bootstrapped from) or `PROVENANCE_UNVERIFIED` (existence or attribution could not be conclusively established in this pass — never guessed).

All report links are repository-relative. Ledger bootstrapped at governance phase `APPSEL-BACKEND.GOV.0`, from HEAD `6734b00db43de67f1d21e1121bf2ab88e7006a4a` (branch `main`).

This bootstrap fully ledgers the **currently active 10K program** (`PHASE_10K_GEN_*` and `PHASE_10K_FREQ_*`, 35 reports) plus this governance phase itself, because those are the phases realistically usable as parent authority for near-term work.
