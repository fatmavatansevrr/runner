## 27. Target-authority composition model

`ProjectedTargetAuthority` is an internal sealed record with: `Cell` (the exact approved dark quadruple), `PilotLabel` (verbatim per-target string), `MinimumCoreWeeks` (parent-family, from `RaceHorizonPolicy`), `PreferredCoreWeeks`/`MaximumCoreWeeks` (exact-target, from that target's horizon policy), `DecideHorizon`/`ClassifyHorizon`/`GetUnsupportedReasonCode` (bound `Func<>` delegates to that target's own policy methods — provenance stays with the original class, not this record), `VolumeSafetyPolicy` (a direct reference to that target's own named singleton instance), `BuildPeakVolumeBand` (bound delegate to that target's own band-policy `Build` method), and `PeakVolumeBandMinimumKm`/`MaximumKm` (surfaced for assertions only). The record freezes no new number and computes nothing; every member is a reference to an existing owner.

## 28. Typed cell/key model

The key is `Dark16KPilotEligibilityPolicy.ApprovedDarkTargetDistanceCell` — the same record type the dark-eligibility gate already uses — a `(TargetDistanceKm, ParentDistanceFamily, Level, RunsPerWeek)` quadruple. No new key type was introduced; this deliberately reuses the existing eligibility type so an authority can never exist detached from an approved cell.

## 29. Authority registry/resolver

`ProjectedTargetAuthorityRegistry` is a static class holding a `Dictionary<Cell, ProjectedTargetAuthority>` built once from an explicit 3-entry list. `TryResolve(cell)` returns `null` for a `null` cell or a cell with no exact dictionary match — verified by audit: the lookup is `cell is not null && ByCell.TryGetValue(cell, out var authority) ? authority : null`, i.e. plain dictionary equality over the full record, no distance tolerance, no `OrderBy`/`.First()`/nearest-match logic anywhere in the type. `BuildIndex` throws `InvalidOperationException` on `TryAdd` failure (duplicate cell), verified by dedicated test `Registry_DuplicateRegistration_FailsLoudlyAtConstruction_NeverSilentlyPicksOne`, which actually invokes `BuildIndex` with a duplicated entry and asserts the throw and message content — this is not merely a name-implies-behavior assumption. `BuildIndex` is `internal` (not `private`) solely to allow this direct test exercise, gated by the pre-existing `InternalsVisibleTo` grant.
