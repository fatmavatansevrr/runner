# Domain Wave 2 Component Vocabulary

Shared internal vocabulary: `WARM_UP`, `MAIN_SET`, `RECOVERY`, `COOL_DOWN`.

User labels: Warm-up, Main Set, Recovery, Cool-down.

`FARTLEK v3` uses `WARM_UP, MAIN_SET, RECOVERY, COOL_DOWN`. `RECOVERY` means recovery segments between variable efforts, not a separate post-workout recovery block.

`THRESHOLD_TEMPO v3` uses `WARM_UP, MAIN_SET, COOL_DOWN`; `RECOVERY` is rejected for this continuous-tempo artifact.

`EASY_STANDARD v3` and `LONG_RUN_STANDARD v3` omit `components`. No duration, distance, pace, recovery seconds, or repetition values were added.
