## 20. Beginner 4D minimum weekly volume (exact, re-derived this phase)

**`Beginner4DMinimumRepresentableWeeklyVolume = 9.0 km/week`**, precisely re-derived (superseding GEN.4B's earlier ~8.5-10.0 km approximate range), using the now-confirmed exact formulas:

```
LongRunDistanceKm = Round0.5(0.33 × weeklyVolumeKm)          [normal target share, no overrides applicable]
residual          = Round0.5(weeklyVolumeKm - LongRunDistanceKm)
requiredMinimum    = MinimumKeySessionDistanceKm(3.0) + 2×MinimumEasySupportDistanceKm(1.5) = 6.0 km
infeasible if:     residual + 0.001 < requiredMinimum
```
At `weeklyVolumeKm = 9.0`: LongRun = Round(2.97) = 3.0, residual = Round(6.0) = 6.0, `6.001 < 6.0` is false → **feasible, exactly at the boundary**.
At `weeklyVolumeKm = 8.5`: LongRun = Round(2.805) = 3.0, residual = Round(5.5) = 5.5, `5.501 < 6.0` is true → **infeasible**.

At exactly 9.0 km: KEY=3.0, EASY1=1.5, EASY2=1.5, LONG=3.0 — every per-role minimum met exactly, no slack. Classification: `APPSEL_INTERNAL_REPRESENTABILITY_CONSTRAINT`. Explicitly not conflated with scientific optimum or a starting-volume default (both are set with margin above this floor, §6-7).
